**Task 2:** HTTP Status Codes
**Chi tiết:**
- Học ý nghĩa và khi nào dùng status codes:
  - **200 OK**: Request thành công, có data trả về (list, detail)
  - **201 Created**: Tạo resource mới thành công (create)
  - **204 No Content**: Request thành công, không có data (delete)
  - **400 Bad Request**: Request sai format
  - **401 Unauthorized**: Chưa đăng nhập hoặc token invalid
  - **403 Forbidden**: Đã đăng nhập nhưng không có quyền
  - **404 Not Found**: Resource không tồn tại
  - **422 Unprocessable Entity**: Validation failed
  - **500 Internal Server Error**: Lỗi server
- Practice: Return đúng status code cho từng trường hợp

**Kết quả:** Hiểu và sử dụng đúng HTTP status codes
